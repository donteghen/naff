How to use this run-through

  1. Do part 0 once, then go through the parts in order: each part uses what the previous one created (accounts, drivers, orders A–E).
  2. Every test says where to do it: SITE customer site, DRIVER driver app, PANEL admin panel, CLI terminal. Tests tagged ABLY or SMTP need those env variables; Skip them otherwise.
  3. Click Pass, Fail or Skip. A failure opens a note box: write what you saw (and the NF- number). Results stay in this browser. Use To do / Failed to filter, and Copy report to share.
